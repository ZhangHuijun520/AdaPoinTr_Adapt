# SCQ-RF草案评审与修订说明

_评审日期：2026-11-14｜依据SCQ B／S冻结证据、实际计算图与本次公开文献检索｜不实施、不创建执行请求_

## 1. 总体判断

原草案具有合理的科研基础，尤其是将RF-Requery与同容量RF-Static比较、保留完整骨块E／J评价、坚持D-only推理、禁止按失败例临时改参数。这些设计值得保留。建议在修订后开展一次有预算上限的证伪研究，而不是直接按原稿启动最多八次训练。

需要修改的核心不是再堆一个模块，而是澄清：**第二次坐标校正之前重选Memory邻居，是否提供可观察的额外价值；该价值能否超过相同额外头与训练适应的作用，并保留相对于S的完整几何收益。**

原稿关于F归因、第一步补偿保留、近邻可行性、严格风险门和训练预算仍有若干不相容或不够精确之处。以下逐项说明。最终建议落实在[修订后的正式计划v2](Cranial_BCSP_FullMamba_SCQ_RF_下一阶段正式实验计划书_zh_2026-11-14_v2.md)。

## 2. 与既有结果相符、应保留的设计

1. 原S在两折E／J平均改善，但新增严重失败没有消失。继续研究空间条件有依据，宣称可靠替代尚无依据。
2. Qraw偏位不是失败专有现象。195／210例Qraw质心>20 mm，205／210例被SCQ拉近；不能由四例展示推出Qraw头故障。
3. 大幅残差通常有用。禁止把“位移大”直接等同“不可靠”，也不应未经对照给Qraw增加强GT监督。
4. Static与Requery均在Q1坐标下构造几何，只改变第二次邻居索引。这是比“Requery与没有第二个头的S比较”更有信息价值的消融。
5. 任务保持残缺骨完整边界→缺失骨块完整边界，不能退回仅外板面片；接口指标与反向离群应继续保留。
6. 两折单seed是开发证据，来源内五类缺损相关、训练集跨折重叠；不应以210个病例冒充210个独立患者。

依据：[B／S正式报告](../cranial_bcsp_scq_BS_20261114/SCQ_BS_阶段正式实验报告_zh_v1.md)、[全210例诊断](../../outputs/scq_Qraw_cohort_20261114_v1/Qraw偏位专属性与补偿协同_全队列诊断报告_zh_v1.md)。

## 3. 建议修改的关键问题

| 草案内容 | 问题与影响 | 正式版修订 |
|---|---|---|
| F训练必须先完成、不可跳过 | F回答7维显式几何增量；RF-Static／Requery回答邻居重选，两者不是逻辑前提关系。强制串联会消耗2—4个run且推迟核心问题 | F列为独立归因分支，默认不阻塞RF；若未执行，禁止宣称显式几何独立贡献 |
| 保留旧S有效第一步补偿 | 若全部从头端到端训练，第一头及编码器会适应第二头；仅保留结构和初始化，不保留旧checkpoint的功能 | 默认从头匹配三臂；明确Q1在RF中是中间变量，无新增Q1损失。冻结母版微调属于另一研究，不混入本轮 |
| 重新查询提供新的空间条件 | 原LQI已按最终query位置计算cross-KNN，S已经在Q1处读Memory | RF新增的是解码前坐标反馈；不能把现有S误称只读Qraw旧邻居的全网 |
| 两次残差均零输出初始化 | 从头构建时delta0=0，N1=N0，首个初态不能显示重查询差异；零初始化也可能让第一层首步梯度为0 | 人工测试包含非零固定首残差／不同邻居fixture；实际可行性用冻结训练后S，只是存在性检查 |
| 近邻距离下降支持机制 | N1本来就是Q1的最近8邻居，距离不大于旧集合是KNN构造性质 | 距离只作一致性检查，不能当信息有用或解剖对应的证据 |
| 邻域“近乎不变／无意义差异”就停止 | 未定义容差，容易形成主观或事后门；小样本阴性不代表全部训练轨迹无变化 | 精确相同则报告局部未见差异；微小差异不自动判定有效，状态记为证据不足，不滚动扩样 |
| 保存第一步的有效性但损失只作用Q2 | 端到端训练允许Q1→delta1协同，Q1可能漂移；这不是实现bug | 明确无Q1独立准确性承诺，最终E／J与全量阶段轨迹为评价依据 |
| F≈S／Requery≈Static | “≈”没有等效界限，单seed无显著差异也不是等效 | 不进行未经定义的等效声明；按固定差值、来源分布和门判结果 |
| 零新增严重就称可靠性改善 | 这是可选择的严格研发门，不能替代总体风险量化，更不能证明总体零风险；S-ref若无严重病例则“至少恢复1例”不可满足 | 区分机制支持与严格晋级；S-ref=0时恢复条件不适用，只能说保持本样本零严重 |
| 长尾“不能系统恶化” | 含糊，留有事后解释余地 | 明确对每折均值／来源中位差／风险计数检查，不新增临床含义 |
| 最多6／8个run但顺序不明确 | 可能先做F、又重训参考、随后临时补模型 | 默认S-ref／Static／Requery两折共6run；F仅在开始前登记时增加2run，总上限8 |
| 更换GPU就一定重训全部历史基线 | 不同硬件需披露，但没有必要恢复所有历史B／F0模型 | 在当前统一环境重训S-ref即可；历史B／S只作脉络，不承担新结构的严格主对照 |
| 首次Mamba几何校正／纯Mamba文献叙述 | 已有局部SSM、几何残差和动态节点研究；部分Mamba标题论文实际有cross-attention | 收紧创新表述，按正文／摘要核验层级标记，不先承诺论文新颖性 |

实际LQI源码在`forward()`中以`q_pos`生成self／cross KNN；SCQ候选传入的是Qused。这意味着RF不是第一次让修正query接触Memory。[源码](../../outputs/cranial_bcsp_fullmamba_20261110/lqi_implementation_v1/bcsp_lqi_decoder_v1.py)

原稿参考说明将B／S报告描述为“本次上传的15页PDF”，本次实际核验的是本机冻结Markdown报告及JSON／CSV证据；正式版不继承未经核实的页数或附件格式。另将CUDA规格明确为5 forward／4 loss／4 backward／0 step，其中S-ref一次forward专门提供同环境初态等价基准，避免执行时临时增加调用。

## 4. 文献核对后的研究定位

本次检索覆盖Mamba点云补全、2026年新近生成／域适配补全、经典动态节点及颅骨直接相关研究。专用学术检索连接器当前未提供，采用公开期刊／会议页面、作者arXiv正文及出版摘要。没有声称已取得用户所列全部论文全文，也没有将网页摘要等同源码核验。

| 研究 | 本次可确认事实 | 对本计划的实际影响 |
|---|---|---|
| CompletionMamba，TIP 2025 | 出版摘要描述欧氏局部SSM及shape code | 局部KNN与Mamba本身不构成新颖性；需要重选邻域匹配消融。[来源](https://pubmed.ncbi.nlm.nih.gov/40853794/) |
| FusionMamba，Information Fusion 2026 | 出版预览含空间感知聚合和将合成proxy与输入几何先验残差融合的Correction Module | 与“输入几何＋残差校正”存在直接重叠，尚未取得全文以排除相同重查询策略。[来源](https://www.sciencedirect.com/science/article/abs/pii/S1566253526002575) |
| 3DMambaComplete，arXiv v2，2026-05-19修订 | 开放正文明确包含Cross-Attention Block及HyperPoint Spread | 应记录具体版本；不能当作已核验的完全无attention模型。[正文](https://arxiv.org/html/2404.07106v2) |
| AnchorFormer，CVPR 2023；CRA-PCN，AAAI 2024 | 公开论文已涉及动态区域节点与跨分辨率渐进重建 | 不宣称首次动态局部读出或首次二阶段细化；不将其attention模块搬入当前母版。[AnchorFormer](https://openaccess.thecvf.com/content/CVPR2023/html/Chen_AnchorFormer_Point_Cloud_Completion_From_Discriminative_Nodes_CVPR_2023_paper.html)、[CRA-PCN](https://ojs.aaai.org/index.php/AAAI/article/view/28268) |
| DAPointMamba，AAAI 2026 | 会议摘要侧重跨域patch扫描、空间／通道对齐 | 不等同颅骨接口任务，保留为方法近邻。[来源](https://ojs.aaai.org/index.php/AAAI/article/view/37596) |
| DAPointRWKV，2026-11-07 arXiv | 近期预印本描述局部token引导的渐进decoder与结构稳定化 | RWKV不是Mamba；仅作为邻近循环模型研究，不据此改主干。[来源](https://arxiv.org/abs/2611.10353) |
| MedPCFM，2026-06-23 arXiv | 提供SkullFix／SkullBreak医疗补全、确定性PTv3和flow matching对照 | 后续投稿需要同任务强基线，但当前不同时改变生成范式；不能跨表示／划分直接排名。[正文](https://arxiv.org/html/2606.24433v1) |
| 颅骨迭代低分辨率点云，MICCAI 2023 | 已将颅骨缺损重建表述为点云补全并迭代生成高分辨率结果 | 颅骨点云及迭代本身已非空白。[来源](https://arxiv.org/abs/2308.03813) |
| CDRMamba，BSPC 2025 | 出版摘要描述3D U-Net与Mamba的医学影像修复 | 不能声称首次Mamba颅颌面重建；表示及指标不同。[来源](https://www.sciencedirect.com/science/article/abs/pii/S1746809424014344) |
| Fishman等，IJCARS 2024 | 出版摘要研究临床植入体内外表面厚度与rim设计差异 | 完整骨块边界与可制造临床implant仍需区分。[来源](https://pubmed.ncbi.nlm.nih.gov/38430381/) |

本轮最合理的定位是一个**特定计算图中的匹配机制试验**：第一次coarse补偿之后，在解码前重新读取输入Memory以再次改变坐标，是否优于固定旧邻居。若成功且多seed／独立来源确认，才考虑将其发展为论文核心；“加第二头有效”不自动证明重查询独立有效。

## 5. 建议的投入顺序

建议先进行一次限定的计算图确认与十例以内实际邻域可行性核查，再决定RF实现；不要先支付F两折训练预算来回答一个并非RF准入前提的问题。十例核查仅证明当前训练后S中是否存在条件差异，不评价RF性能，也不追加参数扫描。

若存在可区分条件，则集中完成隔离实现、针对性CPU检查和一次人工CUDA准入，之后再分阶段申请同设备S-ref／Static／Requery训练。默认六个run、两折固定协议；F作为独立归因预算，若开始前选择加入则最多八个run。不根据C折结果修改D折。
