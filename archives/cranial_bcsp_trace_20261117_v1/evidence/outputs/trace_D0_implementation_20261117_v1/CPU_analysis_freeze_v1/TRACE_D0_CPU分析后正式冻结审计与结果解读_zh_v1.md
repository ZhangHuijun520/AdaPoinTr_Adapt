## 二、核心问题与主要结果

本轮主要问题不是“Memory点是否存在”，而是：**Sobol探针到Memory的距离，是否与G2相对G1的E P95回退形成两折一致的正向关系，从而值得投入A=S候选训练？**

主要指标R_case为病例内探针最近Memory距离除以Memory典型间距后的中位数。Delta E=E_G2−E_G1，正值表示G2回退。主要关联仅使用哈希补充、非压力案例，每病例一个来源；5个已曝光案例不参与主判断。

051和072的大幅回退并不伴随本组特别大的典型探针距离；改善病例012的同类距离也接近它们。因此，仅靠“探针离Memory太远”不足以解释这组最重要的失败和改善。008的距离较高，说明个别失败可以同时具有支撑稀疏现象，但不能由单个压力案例推导总体根因。

这些病例此前已被结果选择和讨论，只用于解释边界，不能加入主要关联让结果转为阳性。Delta E为个体病例差值，不是来源五类型均值，不应与SPCG来源均值混为一谈。
