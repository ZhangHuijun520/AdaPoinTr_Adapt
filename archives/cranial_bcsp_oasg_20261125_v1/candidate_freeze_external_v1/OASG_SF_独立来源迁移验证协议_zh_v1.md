## 1. 科研问题与结论边界

在 SkullBreak 训练得到的 OASG 是否能将首次粗点放置、最终补全和接口收益迁移到 SkullFix 的不同缺损构造。主比较为同病例的 A（OASG＋LQI）对 B（原 Global 粗生成＋LQI），从残骨预测缺失骨块的完整边界。保留本研究已有的骨组织全边界表示。

已冻结的 SkullBreak 证据为第一种子 Fold C／D、第二种子 Fold D，均通过原六组门槛。第二种子在 Fold D 的效应幅度较小。唯一新增严重病例 `train__037__random_1` 的 A 臂在粗点时已明显漏覆盖，密点展开有所改善。此次复核只描述该病例与一个同型对照，模型不随复核结果修改。

SkullFix 与 SkullBreak 均由 CQ500 派生。作者报告发布版两数据集不重叠，并记载两种缺损构造的差异。项目本地冻结清单中，SkullFix 90 个完整骨文件哈希与 SkullBreak 84 个来源的完整骨文件哈希无交集。哈希检查只能识别字节相同文件。实验定位为 **同一母数据集下、不同发布数据和缺损构造的跨数据集迁移**。患者级独立性取决于下节的溯源证据。跨中心或真实临床缺损泛化须另行验证。 [Kodym 等，数据集原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC8100897/)

## 2. 冻结模型和病例

- 固定使用 **Fold D／seed 2026112102** 的已审计最终 B／A 权重各一份。采用最新完成的复现对作为事先固定的候选。各 checkpoint 路径、字节数及 SHA256 见候选冻结索引。执行前实测权重字节并核验训练身份。同一对模型用同设备、软件、输入与调用顺序。禁用微调、BNCal、测试时增强、对齐、选权重和替换粗点头。
- 候选队列是现有 SkullFix 开放清单的 **90 例**，由项目中标为 train 的 80 例和 val 的 10 例组成。对本实验两组均只作外部评价。病例顺序沿用 90 例清单。每源一例时来源等权亦为病例等权。80／10 原分组只作描述。不得访问留出的内部测试数据，亦不使用组织者封存的 GT。
- 检查本地两份清单与对应官方发布版的来源及映射链，记录发布版和解包来源、病例／来源标识、可用的去标识化母病例 ID、已知重复或来源不明项。对照范围为已用于候选开发的全部 84 个 SkullBreak 来源。官方发布映射及来源记录没有矛盾时，方可称为作者确认不重叠的发布版来源。若能获得母病例映射，另行核实患者级不重叠。若发现实际重叠、版本不符或无法将局部文件追溯到发布版，暂停现有 90 例主分析，先出证据表并另行确认；禁止事后按模型结果排除或补选病例。
- 记录 90 例既往参与几何审阅和表示准备的范围。该队列的模型配对验证在预测前冻结，论文披露上述使用历史。

## 3. 数据准入与预测边界

1. 一次限定本机 QC，锁定 90 例点集、原始 triplet、相同坐标与表面参考的证据。确认完整骨体素与残骨／植入块的互补关系、共享切壁、正反法向和 NRRD 空间变换，验证 affine、轴方向、单位及归一化往返。重用已有 QC 可核验项，补缺项。历史批量 QC 对 90 例均记录警告，逐类解释及验收，禁止将历史通过视作警告已消除。
2. 固定既有 V1 的 8192 点残骨输入、确定性采样及由残骨得到的归一化。其已知 FOV 封盖处理保持一致，按已有标志描述并记录 E/J 参考面是否受影响。历史材料中目标 G 的 FOV 面计数为 0，仍需以本次实际评分资产确认。若某病例无法获得有效 E 与 J 参考，暂停并报告，不静默丢弃或改阈值。
3. 为预测冻结仅含残骨坐标及残骨归一化参数的独立只读输入包。完整骨、植入体、目标点和 E/J 参考只由后续离线评分读取。正式评分沿用实测世界毫米坐标、面积加权 A1、A2 反向参考与 GT 点集定义。冻结参考生成代码、版本、每例哈希与坐标合同。
4. 准入通过后，才创建 **180 次完整 forward** 的待授权请求。每臂同序 90 例、batch 1、eval、FP32、256 粗点及 8192 密点、每粗点 32 子点。保留原生父子索引及 A 臂 S、δ 和 token 索引。运行计数闭合，预测前后模型状态与 RNG 留证。失败即停。之后先冻结归档及全部成员，再统一 CPU 评分和只读评分审计。

## 4. 指标、判定与汇总

沿用 SkullBreak 的 Native 指标及物理阈值。每例先算 A−B，再按来源等权。主指标为密点 E P95，接口及严重失效为可靠性条件。使用固定来源顺序、PCG64 seed 2026112401，2000 次按来源有放回重采样，冻结抽样索引。报告双侧 95% 百分位区间、改善来源数、逐来源留一范围及病例级变化。置信区间描述这对固定权重下的来源差异。病例配对不跨数据集混合。SkullFix 的 80／10 组仅描述，禁止用其中一个子组代替总体裁决。

| 门槛组 | 条件（用未舍入值） |
|---|---|
| 粗点机制 | E P95 Δ ≤ −0.50 mm。若 B 粗点 far20 ≥ 2.00%，要求 Δ ≤ −1.00 个百分点，否则 A ≤ 2.00% 且 Δ ≤ +0.25 个百分点。 |
| 密点收益 | E P95 Δ ≤ −0.50 mm，且至少 60／90 个来源严格改善，延续原 2／3 规则。 |
| 密点接口 | J P95 Δ ≤ +0.25 mm，J Cover@2 Δ ≥ −0.50 个百分点。 |
| 密点反向 | 反向 A2 P95 Δ ≤ +0.50 mm，far20 Δ ≤ +0.25 个百分点。 |
| 密点严重失效 | 密点 E P95 > 20 mm 或 J Cover@2 = 0 判为严重。A 严重总数 ≤ B，新增严重 ≤ 1／90。此上限按原最大率 2／105 向下取整，保留新增、挽回、共同严重的逐例名单。 |
| 来源级不确定性 | 密点 E P95 的 95% 来源级区间上端严格小于 0。 |

若六组全过，报告该固定模型对在已核验 SkullFix 范围内的零微调迁移证据。若仅区间未通过，登记为证据不足。若粗点改善而密点或可靠性未过，报告可支持的阶段性结论和确切门槛余量。若来源、几何或执行前提缺失，暂缓裁决。任何结果均保留完整配对并冻结，结构调整或扩样另行立项。
