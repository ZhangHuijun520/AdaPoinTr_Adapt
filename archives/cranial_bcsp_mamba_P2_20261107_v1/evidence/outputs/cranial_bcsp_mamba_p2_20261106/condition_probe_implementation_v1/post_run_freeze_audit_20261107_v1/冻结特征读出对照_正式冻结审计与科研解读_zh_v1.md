## 6. 对H2的含义与下一步

四个冻结模型上，特征读出的质心与半径来源均值均优于原coarse，支持全局特征中存在可读出、而当前coarse头未充分利用的低阶几何信息。仍需结合多数来源和两模型的绝对水平解释，不能据此证明结构耦合一定改善完整表面。

固定线性读出优于coarse时，支持相应目标的信息可以被简单映射利用；不能证明原坐标头完全忽略输入。若它不优于coarse，也只是否定本次固定线性／正则读出，不构成信息不可预测或必须增加定位器的证明。

是否继续一个H2，应依据本表中跨折稳定的具体目标提出唯一假设，并明确如何把D-only预测条件进入coarse、OFF恒等路径以及AUX／COUPLE公平对照。此次不自动设计／实现H2，不扫描lambda或增加训练；完整表面E／J覆盖、远端离群和新退化仍须由后续同协议模型实验检验。

当前是单seed、已多次使用的开发来源上的探索性结果。读出四维矩不构成高精度骨块、接口匹配、厚度／拓扑或临床可靠性证据；也不把GT对齐／Oracle结果混入正式性能。
