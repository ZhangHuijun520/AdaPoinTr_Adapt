# 冻结特征诊断：科研结论与 H2 决策边界

日期：2026-11-07。前提：`FORMAL_POST_PROBE_FREEZE_AUDIT_PASS`。这是正式审计后对已保存数据的解读，不新增实验、参数搜索或 H2 执行授权。

## 1. 最重要的结论

**模型已在利用输入条件；冻结特征中仍有可读出的低阶几何信息，尤其是骨块范围。M0 的整体位置问题尚不能主要归因于 coarse 坐标头。**

已有 coarse 的定位明显优于训练常数和此次简单输入几何读出，反对“模型完全不看输入”的解释。冻结特征读出又在四个模型上降低中心与半径的来源平均误差，支持相应信息可以被另一种固定映射利用。两者可以同时成立。

读出监督的是 G8192 表面采样的经验质心与 log 半径，不是实际实体体积矩，更不是完整骨块点集。因此本次结果不等于补全、接口或临床效果提升。

## 2. M0 的定位与范围证据应分开

| 对象 | C 折 | D 折 |
|---|---:|---:|
| coarse→特征读出质心误差，mm | 11.777→11.393 | 12.890→12.387 |
| 质心改善／退化来源 | 11／10 | 12／9 |
| 质心误差/rGT 的均值变化 | −0.003318 | −0.000318 |
| coarse→特征读出绝对 log 半径误差 | 0.11213→0.07112 | 0.15117→0.09546 |
| 半径改善／退化来源 | 19／2 | 18／3 |

半径误差的来源平均值约下降 36.6%／36.9%，来源方向也较一致。质心误差只下降约 3.3%／3.9%，归一化定位指标几乎持平，来源胜负接近。这是可读出范围信息的较强描述性证据，而非已解决定位问题的证据。这里没有训练 seed 重复或显著性推断。

固定 lambda=1 的线性读出限制了结论范围；失败或小收益不证明 encoder 中没有其他非线性、局部或被池化丢失的信息。本次也不能从全局特征探针区分 encoder 与 max pooling 的各自贡献。

## 3. 不可忽略的反例：frontoorbital

M0 的 frontoorbital 质心误差在 C／D 两折分别增加 **0.770／2.392 mm**，尽管半径误差在两折都下降。其他四类的质心均值改善抵消了这类回退，形成全局均值的小收益。

这说明不能按总体均值直接替换中心或硬裁剪 coarse 范围；“半径更准”不保证位置更准，更不保证复杂骨块覆盖更完整。后续如果开展 H2，必须完整保留这类病例，报告分层与新退化，而不能排除它来提高均值。

## 4. Transformer 对照如何解释

T0 的特征读出质心误差在 C／D 为 15.872→14.763、13.085→11.297 mm，两折均为18/21来源改善；半径误差也下降。这说明读出余量不是 Mamba 独有现象，不宜包装成 Mamba 专属缺陷或创新。

T0 与 M0 的原始误差、表示和训练轨迹不同；单 seed 下不能以探针收益幅度直接比较 encoder 的全部信息量。M0 在 C 折的绝对定位仍优于 T0，D 折则应单列，不能只比较改善幅度。

## 5. 简单输入几何对照提供了什么

训练常数的质心误差约57 mm，18维几何读出约32–34 mm，均明显差于模型 coarse。这表明训练先验或此次固定输入统计不足以替代已经学到的条件映射。

同时，这只否定当前18维摘要＋固定线性ridge的竞争力，不否定所有 D-only 几何条件。不能从一次线性结果跳到“缺损从残骨中不可定位”，也不应自动扫描更多几何摘要、正则或定位器。

## 6. 与 H1 负结果的联合解释

H1 提高部分 coarse 矩，却使两折完整表面 E／J P95 和 CD 回退。当前读出诊断说明某些矩在冻结特征上可预测，却没有证明把这些矩耦合进生成过程就会改善表面。

二者共同支持的问题应表述为：**可预测的输入范围条件，怎样进入 coarse／dense 生成路径，才能改善实际形状覆盖而非仅满足全局矩？** 不能把“另加一个质心／半径损失”重新命名为 H2，重复 H1。

## 7. 建议的下一步边界

先起草唯一 H2 的最小假设，优先讨论有较稳定证据的范围条件如何软耦合进生成路径，并把 M0 定位收益弱、frontoorbital 回退与全局矩不足写成明确反证风险；本次不直接冻结公式或认定该机制有效。

后续方案至少要明确：推理只用 D；OFF 路径与原 M0 恒等；AUX／COUPLE 使用相同条件头、参数与监督；区别仅为预测条件是否进入生成；不得硬替换中心或按开发结果选择病例；最终仍评价完整骨块、E／J覆盖、离群和新增严重退化。若不能形成上述单一、可证伪的机制，则停止而非扩大探针搜索。

本次没有选择或实现 H2，没有训练新的 backbone，没有 GT 配准，也没有把诊断当成正式模型性能。
