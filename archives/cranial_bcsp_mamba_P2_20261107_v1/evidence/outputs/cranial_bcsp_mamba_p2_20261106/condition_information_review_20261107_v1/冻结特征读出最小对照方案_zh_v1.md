# 冻结特征读出最小对照方案 v1

日期：2026-11-07。状态：`DRAFT_NOT_IMPLEMENTED_NOT_EXECUTABLE`。这是既有证据复核后的具体补证范围，不是GPU执行授权，也不提前选定H2。

## 1. 唯一问题

对应折的冻结encoder全局特征中，是否存在可由一个固定线性读出利用、且原coarse坐标头未充分利用的骨块中心／范围信息？

这不是重新训练骨块生成模型，也不把读出预测的四个参数当作新的骨块几何或正式补全性能。

## 2. 固定模型与样本预算

- 只用P1的T0_C、M0_C、T0_D、M0_D最终冻结checkpoint。H1已收束，不增加其探针臂。
- 每个模型访问对应折315训练病例＋105开发病例，各一次encoder/coarse前缀，共4×420＝1680次前缀调用；0次backward、0次optimizer step、0次完整dense forward。不添加病例或seed。
- 每折63训练来源、21开发来源，每来源5缺损；训练／开发来源严格隔离。不能把C模型用于D开发来源并称为未见来源评价。
- D-only几何与G目标摘要每折420行，共840行，同折两模型共享；有重复输入可按文件SHA缓存，但保留每折数据角色，不混用标签拟合。
- 本方案没有绑定当前服务器资源、checkpoint实际恢复路径或精确输入清单，故不创建execution request。实施时只核对这四个模型和既有同任务数据，不扩展库存框架。

## 3. 精确读取位置与低成本提取

读取`base_model.coarse_pred`输入的1024维pooled global feature和输出的256×3 coarse。优先用临时pre/post hook捕获同一实际调用的张量，在coarse头完成后退出，跳过FPS候选、query和decoder；不复制一套encoder计算，也不修改生产forward。

只有可识别的专用退出信号可视为正常前缀结束；其他异常失败即停。CPU人工验证必须覆盖hook清除、异常透传、case配对及无GT进入模型。eval＋inference_mode，BN、参数及RNG前后核对；遵守既有数值和provider合同。有限CUDA梯度非确定性披露保留，本轮不求梯度。

同一次前缀保存Q矩；105例开发Q矩与对应冻结P1记录核对，采用既有数值容差，不新增“恰好通过”的容差。前缀不产生新dense评分。若前缀等价性不能确认，则停止并报告，不自动改成额外1680次完整forward。

## 4. 目标、输入与四种必要对照

所有拟合在D-only归一化坐标中进行。G仅作离线训练标签或开发评价，不输入模型／特征构造。

目标为4维：G8192经验质心三坐标，以及`log(r_G)`，其中半径为中心化均方距离平方根，不加入H1的历史epsilon；实际计算须验证正半径，遇退化停止。各臂评价用相同定义；明确它是表面采样矩，不是实体体积矩。

| 对照 | 具体定义 | 要回答的问题 |
|---|---|---|
| 训练常数 | 对应折训练来源等权目标均值 | 是否只是训练先验 |
| 已有coarse | 同次前缀Q的质心和log半径 | 当前坐标头已做到什么 |
| D-only几何读出 | 18维：xyz均值3、中心化协方差上三角6、每轴10/50/90%分位数9 | 简单输入摘要是否足够 |
| encoder特征读出 | 对应冻结T0/M0的1024维z | 学到的条件能否被简单读出利用 |

xyz分位数固定线性插值；不加入GT缺损中心、切壁标签、source/case编号或缺损类型one-hot。bbox尺度/中心用于既有坐标合同，不把归一化后近恒定bbox量伪装为新信息。

## 5. 单配置CPU拟合与评价

仅拟合上述线性读出，不更新backbone。X、Y均只用训练病例均值／标准差标准化；零方差X列置零，常数Y维只返回训练均值。每来源等权，每来源五例等权。

固定带不惩罚截距的ridge：`mean_weighted(||Y_std-X_std W-b||²)+1.0*||W||²`；所有输出共用该系数。不得把求解器中`X^T X + alpha I`的alpha=1与这里平均损失系数1混淆，必须在人工线性例中核对。无正则扫描、内层调参或开发集拟合，不宣称线性probe逼近信息上界。固定float64 CPU求解，保留系数与训练统计。

主报告分折给出：中心误差mm、中心误差/r_G、绝对log半径误差；每来源5例平均后21来源等权，列对coarse的逐来源差值、均值／中位数、改善／退化数与五缺损分层，不做显著性检验或新bootstrap。既有严重几何病例分层仅描述，不排除病例。

## 6. 如何决定是否提出H2

- 若冻结特征读出在两折都降低中心与半径误差、且多数来源方向一致，可支持“存在当前头未充分利用的可读出信息”。这仍不证明替换坐标头就能提高完整表面覆盖。
- 若几何读出已有同等收益而特征没有额外收益，优先研究简单输入条件；不能强称Mamba特有机制。
- 若只有半径改善、位置不改善或两折相反，保留混合结论；不直接设计多锚点或硬裁剪。
- 若特征读出不优于coarse，只能否定当前线性读出组合，不能证明信息不存在。z无效也不能区分encoder信息不足和max pooling损失，需要另一个具体证据问题，而非默认扩层或扩大probe搜索。

仅在上述结果形成后，写一个H2假设，规定条件进入coarse的方式、OFF恒等路径、可证伪预期及AUX／COUPLE公平对照。完整骨块覆盖与接口收益仍须由后续独立同协议模型实验验证。

## 7. 收尾边界

下一实施只应包含提取短入口、固定CPU读出与必要人工验证；复用既有加载和守卫，不新增通用框架，不重复GPU preflight。完成必要验证、精确资产及设备预算绑定后，生成待授权执行request，之后再单独执行。失败不自动重试或扩大样本／调参。
