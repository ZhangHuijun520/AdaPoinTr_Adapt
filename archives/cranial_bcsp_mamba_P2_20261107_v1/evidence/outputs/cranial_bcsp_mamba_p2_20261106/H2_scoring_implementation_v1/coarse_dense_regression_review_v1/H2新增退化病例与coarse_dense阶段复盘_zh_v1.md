# H2新增退化病例与coarse／dense阶段复盘 v1

日期：2026-11-07。范围：既有冻结评分中的630行模型记录及210病例的配对风险记录。无服务器操作、forward、训练、点集重新评分、Oracle配准、参数扫描或正式gate。

## 1. 研究问题与病例选取

目标是判断已观察到的H2退化在coarse输出中是否已有可见位置／范围异常，以及dense相对位移是否进一步改变这些异常。本报告不把相关性解释为因果。

全量背景使用C/D各105例、每例M0/AUX/COUPLE的记录。重点病例由冻结严重几何定义（E P95>20 mm或J Cover2=0）确定：COUPLE相对AUX新增6例，相对M0新增4例，重叠2例，合并8例、7个来源（C3例来自2来源，D5例来自5来源）。不追加最差病例筛选，不更改阈值。重点是事后失败分层，不能当作无偏泛化样本。

全部8例保留3臂对照，共24行；同时提供630行全量阶段指标，避免把选定失败样本代表全体。

## 2. 证据能回答什么

coarse是模型实际使用的256个中心；dense为8192个最终点。两者均在原始world-mm坐标、无配准。所有病例有同一次forward保存的质心、回转半径与位移汇总；重点8例中仅1例有保存的COUPLE coarse点张量，其余7例不能据此绘制实际coarse空间点形状或计算coarse接口距离。

因此可定位“到coarse输出时已出现的位置／范围异常”，但不能确定异常更早起源于encoder、coarse坐标头、query特征或训练梯度，也不能从半径与质心认证局部切壁形状。未执行delta置零或供体置换，不能将两套训练权重的差异归因为单次缩放。

### 4.1 大幅位置偏移在coarse已有证据

8例中5例在coarse阶段质心误差已>20 mm，dense后仍>20 mm；dense不是这些大偏移首次可观察到的位置。

- C/train__053__frontoorbital：COUPLE为96.17→96.88 mm，几乎未纠正；最终E P95=92.13 mm、J Cover2=0、远端离群100%。AUX质心为32.61→27.35 mm、E P95=11.68 mm，而M0本身也严重失败。它不是“所有基线都正常”的病例，但COUPLE较AUX显著回退。
- C/train__025__parietotemporal及random_2：COUPLE coarse质心分别42.20、37.95 mm，dense仍40.05、30.85 mm。AUX更差，M0未达严重标记。因此这两例同时说明COUPLE缓解了AUX部分失败，却未恢复到M0水平；二者来自同一来源，不能当作两个独立患者证据。
- D/train__079__frontoorbital及train__087__random_1：COUPLE coarse质心59.30、37.24 mm，dense后56.75、34.83 mm。前者M0也失败；后者相对AUX和M0均新增严重标记，且半径比0.942→0.926并不紧缩，说明单一半径诊断不能覆盖位置失败。

### 4.2 另外3例不属于>20 mm质心偏移主导的同一种表型

- D/train__004__random_2：COUPLE质心14.52→13.30 mm、半径比0.629→0.636；E P95=22.93 mm，但>20 mm离群比例为0。这与“预测没有广泛飞离骨块，却未覆盖足够GT范围”的表型相容。AUX半径比0.696→0.700、E P95=12.21 mm。不能用无远端离群推断覆盖正确。
- D/train__060__bilateral：COUPLE质心14.70→14.59 mm，半径比0.640→0.643，E P95=21.19 mm、远端离群0。AUX质心接近而半径比更大（0.683→0.687），E P95=17.19 mm；M0已略过20 mm阈值。这里存在范围/空间分布问题，简单修正质心未必足够。
- D/train__022__random_1：COUPLE质心19.23→14.21 mm得到改善，但J Cover2仍为0，半径比0.745→0.725，E P95=11.44 mm。这是接口未被覆盖的严重标记，不是E P95>20 mm导致；M0也有J Cover2=0。仅靠最终质心改善不能证明切壁吻合。

这3例并非已被证明“纯形状错误”；仍可能包含方向、局部位置和缺损几何差异。现有汇总不足以分离这些因素，只能拒绝“一律由大幅整体平移解释”。

## 5. dense相对位移：代数证据而非因果归因

对每个dense点减去其所属coarse中心得到位移Δ，已保存的汇总满足：

$$r_{dense}^2=r_{coarse}^2+\mathrm{Var}(\Delta)+2\,\mathrm{Cov}(q,\Delta).$$

位移方差非负，而交叉项可能为负，因此位移幅度较大不代表覆盖会扩大。本次630行独立核对半径平方恒等式，以及质心误差变化不大于质心位移模长的三角不等式；只校验保存记录的代数一致性。

重点8例的交叉项均为负，但仅3例dense回转半径小于coarse，其余5例略大。因此不能把“负交叉项”误写成“8例全部被dense收缩”。8例中7例在coarse已满足紧缩标记，dense后仍为7例；第8例是位置失败且半径比未紧缩。dense有局部加重作用的证据，但它未普遍制造这些重点病例的范围异常。

COUPLE实际缩放保持coarse质心不变；因此coarse大幅质心偏移不可能由这一次围绕自身中心的缩放直接平移产生。两训练臂的coarse位置差异仍可能来自辅助目标与重建梯度共同作用后的参数变化。没有干预不能分辨这些路径。

## 6. 结论与下一阶段方向

当前最可靠的结论是：**多数新增严重退化的可见位置／范围异常到coarse输出时已经存在，dense通常未充分纠正；并非全部失败都是整体位置错误，也并非统一由dense相对位移制造。**

据此建议停止把单一全局半径修正作为当前主要改进路线，保留M0比较基线，收束当前H2版本；不扫描尺度、权重或增加训练。若提出下一项最小假设，应优先讨论“由输入局部几何约束的空间位置与各向异性范围如何同时进入生成路径”，并将接口覆盖列为独立验证目标。该方向尚未被本次观察证明有效，不能直接进入实现或训练。

本轮已足够否定“只要把全局尺度拟合好就能可靠改善补全”的强解释。现阶段不必为收束阴性候选追加GPU干预。如果确有必要区分同一COUPLE模型对delta的瞬时依赖，可另行讨论原协议20次干预；这不是本轮完成的内容，也不是自动准入。

现有记录尚不能证明：coarse各点的接口覆盖、内外板分配、具体远端离群空间方向、query特征是否充分利用输入。若下一步需要这些结论，应先审阅已有保存点集的可视化范围；不能把缺失证据写成已证实根因。
