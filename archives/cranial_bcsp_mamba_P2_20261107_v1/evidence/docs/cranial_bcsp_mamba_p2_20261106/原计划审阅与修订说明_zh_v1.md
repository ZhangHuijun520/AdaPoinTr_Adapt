# 原计划审阅与修订说明

日期：2026-11-06。对象：用户提交的《Cranial-BCSP-Mamba P1后续：结构机制与可靠性实验计划书》v1.0。修订后的正式参考计划见同目录 `Cranial_BCSP_Mamba_P2_正式实验计划书_zh_v1.md`。本次仅研究与文档编制，没有实施、服务器操作或实验。

## 一、总体评价

**方向合理，值得继续；原版不能直接照表进入训练。** 它正确抓住了 P1 的主要矛盾：Mamba 在 C 折的改善未在 D 折重现，部分风险在 coarse 阶段已经出现，接口局部指标改善也可能伴随全骨块覆盖退化。以位置—范围—覆盖机制为主线，比继续扩大输入点数、搜索采样或堆叠 loss 更有信息价值。

原计划已经比“加一个定位模块试试”严谨得多：承认 coarse 已有 CD，提出等矩异形等反例，保留负结果，提出 AUX/COUPLE 与两 backbone 的交叉对照，限制开发集推断。本版保留这些优点。

主要修改不是再增加工程门，而是让**数学对象、因果问题、预算与结论的强度一致**。

### H1公式差异为什么必须先解决

现有代码用 `||muQ−muG||/rG`，草案用未归一化三维差；前者对共同旋转保持标量不变，后者逐坐标 SmoothL1 的归约通常不保持同样性质。现有代码还使用 `sqrt(moment+eps)`、`log((rQ+eps)/(rG+eps))`、两项平均。草案另写 epsilon平方和求和，会改变有效惩罚强度。不能给两者同一个“lambda=0.1”便认为实验一致。

本版选择复用已有公式，代价是接受其 epsilon 的历史数值约定并披露不严格尺度等变。若要从数学上重新设计更整齐的损失，应另列候选，不能在这次适配中混入。

### 不建议把梯度夹角作为单独否决条件

梯度方向接近只能说明某个参数点上的局部一致，不能说明未来优化轨迹相同；不同归约、梯度规模与不同病例尾部均可能改变作用。夹角适合解释，不适合替代全形状训练实验。反例测试同理：等矩异形说明H1不充分，不证明它作为辅助项必然无效。

## 三、近期文献如何改变优先级

2025–2026年已有 CompletionMamba、Mamba–Transformer completion 和 FusionMamba。原计划把“简单替换不足”作为起点是正确的；现在应更明确地把论文贡献落到**任务特定的结构机制、完整骨块覆盖与可靠性证据**，避免声称首次Mamba补全或首次几何增强。[CompletionMamba](https://pubmed.ncbi.nlm.nih.gov/40853794/)、[Mamba–Transformer completion](https://www.sciencedirect.com/science/article/pii/S0957417425044410)、[FusionMamba](https://www.sciencedirect.com/science/article/pii/S1566253526002575)。

AnchorFormer与SeedFormer说明区域锚点/coarse seeds已有充分先例；H2必须讲清楚其与颅骨内外表面、缺损切壁和多区域覆盖错误的联系，而不能只画一个额外head。当前只有几何多表面输入，不等于已经实现“多表面语义特征”。[AnchorFormer](https://openaccess.thecvf.com/content/CVPR2023/html/Chen_AnchorFormer_Point_Cloud_Completion_From_Discriminative_Nodes_CVPR_2023_paper.html)、[SeedFormer](https://arxiv.org/abs/2207.10315)。

MedPCFM的PTv3基线更贴近医学点云补全，是最终阶段值得优先检查的强基线。此时同时复现所有Mamba、flow、SDF方法会把小论文拉成无界基准工程，因此正式计划只建议最终候选阶段选择一个可复现强基线。[MedPCFM](https://arxiv.org/abs/2606.24433)。

近期颅骨可信性审查提醒不能把CD或视觉相似当作植入物可用性。但它研究零样本公开模型，不是本项目训练结果；本版采用其评价警示，不照搬失败率，不把它变成当前必须完成实体制造验证的新工程包。[Plausible but Unimplantable](https://arxiv.org/abs/2610.30035)。

## 四、建议的真正下一步

先做一个短而完整的研究工作包：复用已有证据，确认 H1 的唯一公式和真实调用，核对 coarse/dense 的差量图，作出“是否投入一次H1迁移证伪”的事前决定。

若选择投入：实施后先做反例与实际调用检查，再按既定边界创建待授权request；首轮M-H1 C/D最多两次。若不投入：使用现有checkpoint做对应折的coarse/特征可预测性对照，选择一个具体H2，再制定最小实现。

无论选择哪条，均不再搜索采样、不变更8k→8k与3900步、不重复通用GPU准入、不按本折结果调整下一折。只有固定候选展现跨折完整形状收益后，才进入更多seed和外部验证。

## 五、结论的适当表述

当前可说：“P1发现跨折不稳定与coarse空间异常，P2拟研究几何条件的利用和完整骨块覆盖机制。”

当前不能说：“Mamba无法定位缺损”“加入质心半径必然解决问题”“多表面表示已经带来临床级厚度精度”“Oracle改善后的分数代表模型性能”。

若H1改善矩但未通过形状/风险门，负结果本身可用于收窄假设，但不足以独立保证小论文创新。若H2与backbone交互不明显，应写为一般结构方法在Mamba上的实现，不能通过措辞制造Mamba专属性。
