# Cranial-BCSP-FullMamba · SCQ-PRIME 完整实验报告

版本 v1 · 2026-11-22 · 已执行阶段 T1-C · Fold C／seed 2026112101

## 📋 摘要

SCQ-PRIME 复核既有 SCQ 候选在全 Mamba 颅骨点云补全中的开发集收益，并检验真实相对几何通道是否提供超过等容量固定投影对照的增量。本轮在 SkullBreak Fold C 从头训练 B、F、S 三臂，每臂 3,900 次更新。对同一批 105 例、21 个来源完成 315 次原生预测和 525 行统一 CPU 评分。三臂共有初态、设备、完整批次及曝光计数均通过冻结审计。

按来源等权汇总，E P95 为 B **11.349 mm**、F **7.695 mm**、S **8.496 mm**。S 对 B 降低 **2.853 mm**，17／21 个来源改善，接口与严重事件约束均通过。S 对 F 的差值为 **+0.801 mm**，95% 来源级配对 bootstrap 区间为 **[−0.511, +2.032] mm**。相对 F，S 的 J Cover@2 下降 **5.368 个百分点**，严重病例从 **4 增至 6**，新增 **3 例**。T1-C 有六项未达预注册门槛，按协议收束。结果支持 SCQ 组合相对 B 的实用增量，真实几何通道相对固定投影的额外收益未获支持。[预注册方案][plan] · [判定回执][gate]

## 🎯 实验目的与前序依据

历史 SCQ B／S 实验中，S 在两折的开发集 E P95 均值上改善，但 Fold C 出现新增严重失败。历史 LQI 与后续 B 在相同旧 seed、批序和记录初态下仍出现约 **4.405 mm** 的 Fold C E P95 差异，相关运行的设备、驱动或封装边界存在差异，无法从历史证据分离其影响。PRIME 因此训练同设备的新 B，并在同一折与 seed 下引入等容量 F。[历史 B／S 报告][history] · [A0 差量核对][a0]

| 问题 | 对照 | 可回答的范围 |
|---|---|---|
| H-P，组合实用收益 | S−B | 局部 Memory 读取、残差头与真实几何通道的合并增量 |
| H-G，几何通道增量 | S−F | 匹配容量、初态和共享路径后，以真实相对几何替换固定投影的训练后效应 |
| H-R，几何可靠性 | S 分别对 B、F | 接口误差、反向离群及严重事件是否落在预注册限度内 |
| 对照有效性 | F−B | F 是否足以作为可工作的对照，以及共享设计与固定投影联合使用时的表现 |

## 🧩 数据、模型与实验内容

### 任务、表示与划分

输入为残骨 D 的完整骨组织边界表面点云。目标为缺失骨块 G 的完整边界，包括继承的自由表面 E 与和残骨相接的切壁 J。沿用 V1 表面表示，按暴露体素面的世界物理面积采样。D 和 G 各用 8,192 点。模型输出 256 个粗点和每粗点对应的 32 个密集子点。归一化由 D 的包围盒确定，推理输入仅使用 D。离线评分再按冻结中心和尺度恢复原世界毫米坐标。

开放开发范围为 SkullBreak 的 84 个来源、420 例，每来源五类缺损。Fold C 使用 63 个来源、315 例训练，另 21 个来源、105 例开发，按来源隔离。固定开发病例全部纳入，缺损类型包括 bilateral、frontoorbital、parietotemporal、random_1、random_2。Fold C 已用于研发，本轮未进入独立确认集、官方测试或跨数据集验证。[预注册方案][plan] · [预测冻结审计][prediction]

### 三臂模型

| 臂 | 计算路径 | 可训练参数 |
|---|---|---:|
| B | 原 LQI FullMamba，粗点直接进入下游链 | 39,903,169 |
| F | SCQ 残差头＋局部 Memory 读取，附加七维通道为冻结固定投影 | 40,596,676 |
| S | 与 F 共用残差头、局部读取和插入位置，附加七维通道使用真实相对几何 | 40,596,676 |

F／S 从已学习粗查询 Qraw 对编码 Memory 执行 KNN 8。对邻域 Memory 特征逐 token 做 LayerNorm 后，取均值 fₐ 和逐维最大值 fₘ。S 的七维描述量由邻点相对 Qraw 的三维均值、三维标准差与平均欧氏距离组成，标准差使用预注册的数值稳定项。F 对 fₐ 做 LayerNorm，再乘冻结的 7×384 投影 Pfix 的转置。F 仍读取实际局部 Memory，因此其投影随输入特征变化。

全局特征 z、fₐ、fₘ、Qraw 与七维通道拼接后进入 1802→384→3 的 GELU MLP。残差 δ 与粗查询相加得到 Qused = Qraw + δ。F／S 共享新头的初始化字节，末层为零。所有模型沿用原 coarse＋dense Chamfer 重建损失，关闭去噪。当前比较在同一 LQI FullMamba 主干内进行，无法估计主干类型与 SCQ 的交互效应。[预注册方案][plan] · [CUDA 冻结审计][cuda]

## 🧪 实验方法与证据链

### 准入、训练与冻结

人工 CPU 验证覆盖 arm／seed 传递、不同 seed 的初态差、同格共有初态及 F／S 路径。CUDA 人工准入包含 **6 forward、3 loss、3 backward、0 optimizer step**，复核实际 Mamba 调用、有限梯度及六次状态和 RNG 恢复。零初始化末层下，F／S 首次反传的 W1 梯度为零，W2 梯度非零，符合该计算图的预期。CUDA 准入使用的是人工输入。

T1-C 以 **B→F→S** 顺序在同一 RTX 4090 D、同一 UUID、驱动 570.190 上从头训练，正式 seed 为 2026112101。采用 FP32、关闭 TF32 和 AMP、AdamW、初始学习率 10⁻⁴、AdamW betas (0.9, 0.999)、eps 10⁻⁸、裁剪范数 10。衰减组为 5×10⁻⁴，一维、bias 和显式例外组不衰减。第 e 轮学习率为 10⁻⁴×max(0.9^(e/21), 0.02)，BN 动量为 max(0.9×0.5^(e/21), 0.01)。

每臂 batch 8、100 轮，每轮 39 个完整批及 3 个丢弃槽位，共 **3,900 次更新、31,200 次样本曝光、300 个丢弃槽位**。评价固定使用末步权重和训练所得 BN 状态。训练内开发评价、BNCal 和 resume 均未执行。Mamba 有限非位级梯度确定性按既定合同披露。

正式训练审计实测三份 checkpoint 哈希，逐批核对病例及来源顺序。三臂共有模型初态一致，F／S 完整参数及持久状态初始指纹一致。三个训练进程的退出码均为 0。运行回执记录的训练耗时分别为 B 1,498.1 秒、F 1,485.5 秒、S 1,497.3 秒。[CPU 验证][cpu] · [CUDA 冻结][cuda] · [B_C 冻结][trainb] · [F_C 冻结][trainf] · [S_C 三臂配对冻结][trains]

### Native 预测

三臂逐一使用末步 checkpoint，在同一 105 例进行 batch 1、FP32、eval 原生预测。共 315 次 forward、零更新。每例保存实际粗点与 8,192 点最终输出。F／S 另保存 Qraw 与 δ，并各在六个预先锁定病例记录原生邻域索引。审计核对三臂逐例配对、粗密点形状和有限值、F／S 的 Qraw＋δ 数值一致性、邻域索引，以及每臂预测前后的模型状态和 CPU／CUDA／Python／NumPy RNG。归档 320 个成员包括 315 份预测和 5 份日志。[预测冻结审计][prediction]

### 指标和统计

评价使用冻结的 A1／A2 参考，在原世界毫米坐标直接计算距离，未做 GT 配准。A1 使用暴露面中心和物理面面积权重，A2 在每个面内使用四个离散参考点。

| 评价量 | 定义与方向 |
|---|---|
| E P95 | A1 自由表面参考到预测点的面积加权距离第 95 百分位，越低越好 |
| J P95 和 J Cover@2 | A1 切壁的面积加权距离 P95 和距离 ≤2 mm 的面积比例，分别越低、越高越好 |
| Pred→A2 P95 和 far20 | 预测点到 A2 的反向距离 P95 和距离 >20 mm 的预测点占比，越低越好 |
| CD-L1 | 预测与固定 GT 点云的双向平均距离，越低越好 |
| 严重事件 | E P95 >20 mm 或 J Cover@2 = 0，单位为病例 |

评分产生 **315 行模型结果＋210 行共享对照**。共享对照为直接使用残骨点集的 Nop_D 和冻结 GT 点集 GT_8192，210 行均与历史对照分数一致。先对每来源五类缺损等权汇总，再对 21 来源等权。三组对比共享 2,000 次来源级配对 bootstrap，按来源 ID 排序，使用 PCG64 seed 2026112103。95% 区间取配对均值分布的百分位，来源胜负用原精度判断。评分审计从病例明细独立复算来源统计、逐例严重事件转换和 bootstrap，几何距离沿用冻结评分。[评分协议][scoreprotocol] · [评分冻结审计][scoreaudit] · [完整配对统计][pairs]

## 🧭 科研解释和证据边界

1. **S−B 支持组合层面的开发集收益。** 主指标改善覆盖 17 个来源，并伴随严重例数下降。4 个来源仍退化，parietotemporal 类型均值也回退。若引用该结果，应同步报告类型和尾部。
2. **S−F 决定真实几何通道的主张。** F／S 在局部读取、容量、初态与下游接口上匹配。S 的主指标点估计方向与预期相反，接口覆盖的来源级区间完全为负。E P95 区间跨零，当前证据既不足以断言真实几何通道在其他条件下普遍有害，也不足以建立两臂等效。
3. **F 的正向信号值得保留。** F 相对 B 的主指标、接口和反向风险均有改善，18／21 个来源改善。但 F−B 同时改变局部读取、残差路径和固定投影，无法估计各组成的独立贡献。
4. **门槛是事前研究预算规则。** 流程与数据完整，停止由科研指标触发。来源级区间只反映固定训练实例下的来源抽样不确定性，不能估计种子间差异、已曝光开发集的选择偏差或独立泛化。冻结运行合同也不足以保证 Mamba 梯度的逐位重现。
5. **几何可靠性证据限于合成缺损点云。** J 和严重事件由离线阈值定义。实际颅骨植入体的贴合与制造要求需要独立数据和验证。现有证据没有公平比较其他公开方法，也无法据此评估主干交互或端到端效率优势。

后续若另立假设，可先复用既有 Qraw→Qused→dense 输出检查 S−F 的三个新增严重病例和预先固定的普通对照。若要拆开 F 的收益，应事前限定一次只改变一个因素的对照，明确它要解释局部读取、残差路径还是投影输入。本轮预注册判定保持 T1-C 收束。[判定回执][gate] · [冻结结题判定][close]
