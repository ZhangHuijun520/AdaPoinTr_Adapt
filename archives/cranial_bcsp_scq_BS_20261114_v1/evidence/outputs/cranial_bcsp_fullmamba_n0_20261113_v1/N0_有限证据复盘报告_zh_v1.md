# FullMamba 下一阶段 N0：既有预测的有限证据复盘

日期：2026-11-13。**N0-A 已完成；N0 的实际 LQI Memory 证据门仍待补齐。** 本轮没有实施 SCQ，没有获得训练准入，也没有创建训练或追踪 execution request。

## 1. 实际完成范围

复用本机已冻结 F0/LQI 预测、评分、病例索引与正式评分审计。核对两个预测压缩包及其 sidecar 身份，逐一读取并核验 **420 个预测 NPZ 成员**：每模型 C/D 各105例，共210个不同病例、42个开发来源、每来源五种缺损。两折开发来源不重叠。

每个预测仅含 `prediction[8192,3]` 与 `coarse[256,3]`，FP32、finite，`allow_pickle=False`。按冻结 D-only center/scale 转到世界 mm，从实际 Q/P 数组重算质心、回转半径、bbox、协方差谱及 Q→P 代数分解，与既有评分中的对应量比对。未读取真实 GT/D 点集或高分辨率参考数组；GT8192 的质心/半径/谱/bbox沿用绑定评分，不作新的GT几何认证。

E/J/CD、离群比例和风险标签均来自原冻结评分；本轮只汇总，不重新执行最近邻评分，不做 bootstrap、配准、去飞点或重采样。

## 2. 身份与坐标检查结果

420个预测成员的大小与 SHA256 全部匹配冻结病例索引；8192/256点数、数组字段、dtype、finite全部通过。每模型两折病例/来源/type覆盖完整，没有筛除严重病例。

重算的质心、半径、bbox和协方差谱与旧评分一致：最大质心坐标差约1.71×10⁻¹³ mm，最大Q协方差谱差约1.74×10⁻¹² mm²。完整误差见 `completion_v1.json`。

这说明**在本次“归档预测→D-only反归一化→冻结评分几何”的范围内未发现不一致**。本轮没有重新审计原始 NRRD affine、轴方向、体素切除或GT构造，不能据此排除所有上游坐标/数据问题。

每个 coarse 对应32个 dense 点，额外核对：

\[
\mu_P-\mu_G=(\mu_Q-\mu_G)+(\mu_P-\mu_Q),
\]

以及令 Δ=P−Q_repeat 后的平方回转半径恒等式：

\[
r_P^2=r_Q^2+\operatorname{Var}(\Delta)+2\operatorname{Cov}(Q,\Delta).
\]

验证通过。这是同次预测的几何代数，不是独立的因果贡献分解；不能把两个误差向量的模长简单相加。

### 3.1 位置：dense有一定修正，但并未消除上游长尾

- Q→P 的平均质心误差下降：C/F0 1.609mm，C/LQI 1.602mm，D/F0 2.851mm，D/LQI 1.825mm。
- C/F0、C/LQI、D/F0、D/LQI分别有6、3、11、8例从Q偏差>20mm降至P偏差≤20mm；没有例子由Q≤20跨为P>20。它仅描述此阈值下的分组转移，并不代表每例位置都改善。
- LQI C折的平均质心偏差略低于F0，但其中位数更差：Q由9.315升至10.750mm，P由8.466升至9.912mm。不能用均值掩盖分布变化。
- LQI C折仍有11例dense位置长尾，D折13例，不能称已解决定位。

### 3.2 范围：收缩普遍，不能只修全局位置

P半径比小于Q半径比的病例：C/F0 101/105、C/LQI 101/105、D/F0 102/105、D/LQI 91/105；即F0共203/210、LQI共192/210。LQI 的compact标记由coarse的93/210增加到dense的128/210。

**不据此宣布 dense head 有bug，也不建议直接放大半径。** Q是256个中心，P是8192个输出，两者并非同一面积均匀采样分布；半径不是完整形状。负的交叉项和学习到的相对位移可能合理地抵消过大的Q范围，也可能导致漏覆，需要结合E/J区分。P2的尺度修正负结果仍必须保留。

本轮给出协方差特征值和bbox，但未计算GT主轴方向配对，也未做刚体Oracle。因此不能将谱差直接命名为“旋转错误”，不能宣称完成了全部方向/姿态归因。
