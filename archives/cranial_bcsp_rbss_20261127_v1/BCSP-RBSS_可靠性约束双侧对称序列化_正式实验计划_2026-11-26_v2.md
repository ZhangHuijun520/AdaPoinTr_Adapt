## 1. 设计审查与研究判断

**RBSS 值得开展一次有退出条件的几何试点，当前证据尚不足以启动三臂训练。** 草案最有价值的设计是保留 OASG+LQI，在同一母版上只替换一个既有 Encoder 全局分支的 token 排列，同时设置原生顺序与同端点非镜像重配对两种对照。这样能把问题从“对称性是否有用”缩到“可靠反射对应成为序列近邻后，是否比普通跨侧配对多带来可复现的补全收益”。这个问题和 CISC 的切壁空间矩注入不同，值得独立检验。

| 草案的问题 | v2 的处理 |
|---|---|
| 患者坐标方向、真实中线与输入几何平面可能混为一谈 | 先绑定患者物理轴和量纲，再评估残骨估计的反射平面。重复性、跨缺损一致性、解剖准确性分开表述 |
| 最近邻先查全体、再拒绝同侧，可能漏掉真实的对侧支持 | 明确采用候选平面下**最近合格对侧点**，精确查询。将此规则的必要开销纳入冷路径 |
| 配对可行性、指定最优解与控制合格性容易混淆 | 区分禁边图无完美匹配与该确定性解未过后验约束。固定算法和判据，不寻找第二个解补救 |
| 同端点同 K 的 C 仍可能出现不同的整条序列几何 | 加入整体跳跃和局部连续性匹配门，并保留全部剩余差异的描述。估计量限定为相对于该匹配控制的策略增量 |
| 层名、锚点稳定、训练随机流和计算次数有推断成分 | 锁定候选路径，明确实际观察口径、缓存身份、执行阶段、调用上限和停止条件 |
| 日历截止可能驱动放宽门槛或追加平行机制 | 优先一轮无更新试点。截止前缺完整首轮证据时，维持 OASG+LQI 论文主线。EJTC 或其他机制需要独立决策 |

## 2. 研究假设、数据和三臂合同

**假设。** 在同一 OASG+LQI 母版中，把已有双侧观测 token 的可靠反射对应排成相邻项，能改善缺失骨块粗/密 E P95，同时保护 J 与尾部风险。S−R 是整体增量，S−C 是相对于匹配重排的镜像对应增量。

| 臂 | 排列 | 其余条件 |
|---|---|---|
| R | 原始稳定 XYZ 顺序 | 从同一未训练母版按原路径训练 |
| C | 相同双侧端点、相同 K 的严格非镜像边 | 共同激活或共同回退，扫描数、参数和训练合同同 R |
| S | 双向镜像近邻边 | 与 C 使用同一块规则及可靠性门 |

沿用 SkullBreak 开放 84 来源、420 病例，D 折 63 来源／315 训练病例和 21 来源／105 开发病例。每个来源有 bilateral、frontoorbital、parietotemporal、random_1、random_2 五类。输入为残骨边界 8192 点，目标为缺失骨实体完整边界 8192 点，粗查询 256 个，父子槽位 256×32。沿用既有实体互补、D-only 坐标、冻结输入／目标与评分参考。MUG500+ 和封存集不读。SkullFix 90 来源仅在条件复现成功后用于固定权重迁移。两发布同源背景和已有 QC 历史限制其独立性解释。

模型侧只接触本例 D 点、冻结的 D-only 归一化及患者方向元数据。其他缺损、来源 ID、病例类型、完整骨、G、J、缺损掩模及评分结果均不能参与平面、排序或回退。病例 ID 只用于离线分组、输入取件与结果对账。保持原 OASG `Q=S+h(z,F,S)`、LQI、FC、KNN、位置编码、归约、损失和优化器。允许对 permutation 停梯度，原特征 gather 仍反传。目标只改一处全局 mixer 的 order/inverse，正反扫描权重共享、融合及逆排位置沿用原实现。

## 3. 平面、匹配和回退算法

### 3.1 残骨反射平面

世界毫米中使用 `n·(x−c)=b`，c 为 D 的逐坐标中位数。反射为 `x−2[n·(x−c)−b]n`。患者方向 n0=LR，u=AP，v=SI。P0a 核实 NRRD/DICOM 的空间约定、原仿射、物理单位、采样到归一化的映射，及真实训练是否有增强。患者方向只是搜索锚点。对于单例确有可信元数据但反射估计不可靠的情形使用原顺序。整个数据管线的 LR 无法合法恢复，或训练增强改变点行及坐标而又无法保持原合同，则停止当前方案。

A＝D[0::8]、B＝D[1::8] 各 1024 个查询，供体为本例全部 D。对 `n=normalize(n0+tan(a)u+tan(d)v)`，粗网格 a,d∈{−8,0,+8}°，b∈{−16,−8,0,+8,+16} mm。对每个子集自己的粗最优，以角 ±4°、偏移 ±4 mm 做 27 格细化，保留粗最优与固定去重。每个候选在 ±2 mm 外按正负侧分组。反射查询的目标是**另一侧且距平面 >2 mm 的合法供体**，用 exact nearest neighbor，等距取最小输入行号。少于 128 个有效查询行的任一侧判该候选无效。无供体时该项按 10 mm 计。两侧截断距离均值各占一半，覆盖比例按该侧全部有效查询行计，其中距离 ≤5 mm 计命中。距离代价的并列范围相对全体最小值取 ≤1e−9 mm，按 (|a|+|d|, |b|, a,d,b) 排序择一。

两个子集独立搜索、共享供体。两解夹角 ≤6°，|b_A−b_B| ≤5 mm，两侧 overlap 均 ≥0.45，两代价均 ≤6 mm，且未触及总角 ±12° 或偏移 ±20 mm 边界才通过。最终用 A 平面，记录 B 和全部失败原因。距离相同和重复点用人工 fixture 校验。点查询及误差的实现须锁 NumPy／SciPy 版本、浮点精度、输入行序、线程与确定性规则。允许等价加速，但逐例候选、排序和回退结果必须一致。

### 3.2 实际锚点的相邻化

取目标 mixer 的 256 个实际 S，按真实 native ID 和原生排序 `π0` 取 rank。距离在世界毫米计算。每个 S 到其他 token 的最近距离取中位数 `d_med`，非有限或 ≤0 时回退。阈值 `τ=clip(1.25d_med,4,12) mm`，仅平面外超过 3 mm 的锚点参与双侧配对。互为对侧最近反射邻居且双向距离 ≤τ 得 S 边，等距取最小原生 ID。要求 K≥16，且至少 ⌈K/2⌉ 条 S 边由原非相邻变为相邻。

C 用同样左右端点和 K，禁止原镜像配对和任一反射距离 ≤τ 的边。对每个左端点，参考其 S 边长 `d*` 及原秩差 `g*`，允许边代价为 `|d−d*|/max(d*,10)+0.25|g−g*|/255`。端点按 ID 排序，代价量化 1e−6，锁定求解器版本、量化取整及 tie 行为。先检查允许边图是否存在完美匹配，再调用一次最小代价赋值。禁边大整数须严格大于任何可行总成本。成功解还需至少 80% 边长差 ≤max(10 mm, 20% d*)，原秩差绝对偏差的中位数 ≤32，至少 ⌈K/2⌉ 条 C 边从原非相邻变为相邻。求解成功但这些条件失败，记录 `CONTROL_POSTCHECK_FAIL`；只有允许边图不满足完美匹配时记录 `NO_PERFECT_MATCH`。不换解、阈值或端点。

S/C 中每条配对边形成长度 2 的块，块内按原 rank 排序。其余 token 为单点块，所有块按块内最小原 rank 排序并展开。记录并检验两个方向 inverse 恒等。S 的真实镜像边全部相邻，C 在同一真实边集上的相邻率至少比 S 低 0.25。**新增整体匹配门**采用本次拟冻结值。对整条 255 条邻边，S/C 世界跳跃均值之差 ≤max(2 mm, 0.10×native 均值)，跳跃 P95 之差 ≤max(5 mm, 0.20×native P95)。序列相邻边落入任意一端的原生三维 8NN 的比例之差 ≤0.05。另报非配对邻边 P95、绝对秩位移 P95、镜像残差分布、端点数量与未覆盖区域，以揭示仍有的高阶差异。三项整体阈值是对照质量的工程约束，先确认后冻结。

任一门失败，C/S 同时精确回到原顺序。R 直接运行原路径。几何诊断可在离线对 R 的观测上复核，但从 R 延迟中排除不属于原模型的附加诊断。保持 all-case 评价，回退病例须完成原生预测。若 S/C 实际锚点无法逐 ID 对应同一坐标，停止匹配解释。

### 3.3 缓存与跨缺损稳定性

区分平面缓存和排列缓存。平面键覆盖 D 实际有序字节、dtype／形状、坐标变换、方向及估计器版本。排列键另覆盖实际有序 S、原生排列和配对版本。都采用无歧义编码并哈希，失配即重算。原生 S 是否独立于模型权重、训练／推理模式、batch 位置及 RNG 在 P0b 验证。若不能证明，则本版仅允许经预算核验的在线计算，并要求同病例 S/C 共用可核验锚点及计划。训练期间出现锚点或计划失配，停止当前配对。缓存不通过病例 ID 提供推理条件。热路径计入缓存读取、键计算、必要传输和排序执行，冷路径从原始点与合法坐标元数据开始。

跨缺损一致性仅使用训练侧，至少 45／63 来源具有 ≥3 个 plane_ok 病例，其中至少 80% 来源的所有有效病例满足相对本源代表面 ≤8°、≤8 mm。代表面选择角距离和最小的实际平面，同分按冻结病例顺序。共同参照点为该来源五个 D-only 中心的坐标中位数，比较统一朝向下的 `n·(xref−c)−b`。该参照点不输入任何模型或平面拟合器。
