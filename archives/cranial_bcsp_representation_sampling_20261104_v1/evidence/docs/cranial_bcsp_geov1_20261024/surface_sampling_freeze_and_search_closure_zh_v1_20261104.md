# 表面采样方案固定与搜索收束决定 v1

日期：2026-11-04。用户确认：“好的，现在固定采样方案，收束采样搜索”。本文件更新当前科研工作决定；保留此前协议、代码、点集和结果，不改写历史记录，不启动新实验。

## 当前固定方案

**主实验默认采用V1：骨组织完整边界上按世界物理表面积均匀随机采样。** 这是后续模型研究的固定工作基线，不宣称最优采样器。

- 输入为残缺骨D的完整暴露边界∂D，包含分割实际存在的外侧、内侧、孔道／腔体及缺损切壁。目标仍为缺失骨块G的完整边界∂G；不改成完整颅骨或仅原始缺失外表面片。
- V1依照原生体素并集的六向暴露面生成候选；按affine确定的物理面面积抽面，在面内均匀取点。不能把边界体素等权、网格顶点等权或仅取外壳称为相同V1。
- 输入选点只使用D、其坐标关系及冻结随机状态，不使用G、真实J标签或切除体定位输入选点。归一化继续采用各已冻结数据合同的D-only框架，目标共享该框架。
- 当前模型工作设置继续8k输入／8k输出；点数最优性没有因此得到证明，本决定不启动新的点数研究。
- 复用已冻结的具体点集、seed及点序政策。SkullBreak既有嵌套8k点集来自16k候选前缀；不能直接重新抽8k并以“seed相同”为由声称逐点相同。其他数据沿用各自明确绑定的版本，不猜测自动一致。
- 原始前景触及FOV时的截断暴露面及其标志继续如实保留，不借固定方案自动填孔、平滑、删成分或改变几何母版。有限点数不能保证每个解剖表面充分覆盖，也没有可信内外板独立语义标签。

## 搜索到此收束

Morton分层、欧氏固定点数消减、表面图距离等候选的现有证据全部保留。**本阶段不继续调整半径、权重、邻接、采样配额或候选池，也不自动追加采样训练、fold、seed、交叉推理或新病例筛选。** 后续模型对照默认固定V1，不把候选的输入几何收益自动视为模型收益。

| 证据 | 当前解释 |
|---|---|
| V1／Morton配对训练、评价及审计 | Morton改善输入支持，但没有稳定模型主指标／接口优势；不替换V1 |
| 欧氏／图距离配对训练、评价及审计 | 图距离E P95 7.192 vs欧氏6.783 mm，J覆盖46.74% vs53.18%；CD均值略好，但不足以判整体胜出 |
| 同开发集输入几何控制 | 图距离J覆盖79.10% vs欧氏75.44%，输入局部收益没有稳定转化为输出收益 |
| 固定8例空间诊断 | 额眶完整骨片级位置／形态错误在两臂均出现，另有覆盖不足、壳面及切壁误差；不再把主要问题直接归因于采样密度 |

欧氏在本轮两臂中更符合主指标与接口目标，但没有与历史V1的同期公平配对胜出证据。现阶段不将其升级为新的主实验默认，也不为了证明最优采样继续扩展搜索。候选保留为研究记录，未来若有新的明确问题和授权，再另立版本；本文件不提供重启候选的自动触发条件。

## 下一科研主线

优先研究模型对缺损位置条件的利用、目标骨片整体放置与完整形状覆盖，再讨论局部接口精度。现有图像不能确定错误由FPS／proxy、编码器、查询中心、解码器或优化中的哪一步造成。

下一步若要开展实际工作，可在固定病例范围只读核对输入—目标—模型输出空间合同及位置条件传递，再提出一个最小可证伪假设。此处只记录方向，不自动授权代码修改、模型运行、GPU、训练或评价。
