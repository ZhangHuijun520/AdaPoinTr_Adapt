# 固定六例 D-only 接口采样比较报告

日期：2026-11-02。六例既有开发来源、三组既有解析球壳离散设置，各 3 个 sampling seed；无训练／GPU／服务器。

## 结论

**本次固定 PCA 曲率增强候选失败，不进入训练，也不作为新默认采样器。六例的切壁和全局覆盖均下降。**失败仅否定本轮具体算法与固定配额，不能推广为所有局部采样方法无效。

## 冻结方法

输入均为 8,192 点。对照为既有 V1 全表面物理面积均匀采样；候选由 4,096 全局均匀点和 4,096 局部增强点组成。局部定位仅使用 D：先面积均匀采 32,768 候选点，计算 32 近邻局部协方差，以最小特征值／特征值和为曲率分数，选最高约 10% 区域，再在选中体素面内重新均匀取点。没有改邻域、阈值或配额进行扫描。

函数仅接收 D 的面中心、面轴、面积、affine 与 seed。真实病例全部三 seed 选点完成后，才读取 G/C 几何进行评价。J／R／G 不用于局部定位；该隔离为代码调用合同，不宣称进行了操作系统级访问隔离。目标沿用六例既有 G_V1_8192 点集，最终重新核对其 SHA256；本轮没有重新采目标。

## 定位及层面覆盖的解释

最高曲率候选中，到真实切壁面中心≤2mm的比例六例三seed平均仅约 0.417%。曲率对缺损接口缺乏专属性，可能优先选中其他曲面变化和薄层邻域混合区域；本轮没有对所有误选部位做解剖标注，因此不将其统一归因为颅底或噪声。局部重复选面减少了全局有效覆盖。

真实六例仅有 E/J 几何来源标签，无可靠解剖内外板标签，故不虚构真实内外板覆盖率。解析球壳可按 17/20mm 内外半径分层，seed0 的内外层 Cover@1mm 另存 phantom_layer_metrics.json；该标签仅适用于解析模型。球壳尺度小、8k 已较密，Cover@2mm 接近饱和，不能以其通过证明真实接口定位成功。

评价使用全部暴露体素面中心及物理面积作为积分近似，距离和覆盖不是连续表面的精确值。接口支持点数参照切壁面中心，也不是严格连续切壁距离。没有做统计显著性、临床准确性或正式 gate 判断。

## 科研决定

保留全局均匀8k作为当前几何基线，保留原四运行输入密度结果；不追加训练。停止本候选的自动调参和逐点修补。下一步应先查看既有模型在接口的预测误差及 proxy 取点，区分“输入已经包含但模型丢失”与“原始接口支持不足”，再决定是否值得设计专门的 D-only 接口定位。

A0221 不加入本次六例比较，保持其前景质量限制记录。前景清理与接口采样是两个问题，不能靠强化采样掩盖分割伪影。
