# BCSP输入密度四模型开发集配对评价报告 v2

研究阶段：BCSP_INPUT_DENSITY_V1。四个B0 AdaPoinTr模型均已完成固定3900步训练；本报告只记录冻结预测的本机CPU评分，不增加训练、BNCal或GPU调用。

## 结论

本轮主终点的配对区间跨越或接触0，尚未获得16k输入稳定改善未知原始表面补全的证据；这不等于证明两设置等效。

切壁接口的P95与2mm覆盖尚未同时给出方向稳定的改善证据，应保留点估计与区间，不宣称接口吻合已改善。

下述数值均是“病例指标先在同一source的五种缺损间等权平均，再对source等权平均”，不是把210例当成210个独立颅骨，也不是将所有表面点混成一个P95。

## 评价设计与数据来源

- SkullBreak既定开发来源；Fold C和D各21个开发source、105病例，共42个不同source、210病例。各模型只预测自己的开发来源。没有增加病例筛选；本轮不检验SkullFix或MUG500+泛化。
- 每fold比较8192与16384点输入，两臂均输出8192点；输入8k为16k的精确前缀，同病例目标、归一化、训练更新数及已核验批次顺序保持配对。
- 使用训练最终checkpoint及原BN running statistics，native eval/inference_mode、FP32、严格确定性／TF32关闭；不热身、不投票。四模型各105次，共420次forward。
- 输出目标为缺失实体G的完整边界点集；未知原始表面E_G和与残缺骨D共享的切壁J_G分开评分。D-only归一化逆变换到世界毫米，不增加内外板语义标签。
- A1：G的暴露体素面中心，按真实面面积加权。A2：每暴露面固定四子面中心。B：同一G的固定MC三角形中心，按三角面积加权，仅all G；不伪造B参考的J标签。
- 主终点为A1的E_G→预测点面积加权P95。覆盖阈值0.5／1／2mm只作描述。逆向A2／B距离属于离散参考近似；不称连续mesh距离、surface HD95或面积NSD。
- 固定GT8192的CD-L1为双向欧氏最近邻均值之和的一半，单位mm；GT采样控制不视为严格最优上界。
- 差值统一16k−8k：距离负值较好，覆盖正值较好。按42个source配对bootstrap10000次，seed20261024；Fold C／D另外报告，不新增正式gate、p值或多种子推断。

## 可靠性、局限与下一阶段

本机四文件及423个成员与服务器正式冻结审计完全一致。实际输出420模型评分＋630固定控制＝1050条，source层210条（42×5设置）；无效评分记录 0 条。CSV与JSON行数、身份、五缺损汇总及配对均值已交叉核对；未重复运行bootstrap或模型。

模型state与CPU RNG前后不变来自已核验的运行记录；CUDA RNG未记录，不能作同等断言。16k两臂是否有效只能在本轮B0、固定seed0与开发来源范围内解释。两fold训练集有重叠，当前区间不覆盖重新训练、多seed或独立外部测试的不确定性。切壁点距离也不证明实体闭合、连续边界无缝、颅骨内外板语义正确或临床可用。

下一阶段应先据主终点、接口指标、分fold方向及最差source共同选择输入设置。若改善证据不稳定，保留8k作为计算成本较低的默认设置，并把16k作为已报告的表示对照；若主终点改善而接口没有改善，明确区分两条结论，不能据此宣称接口方法创新。随后再提出一项与B0匹配数据、输出点数、更新数及评价合同的Mamba对照，以分离表示收益和模型收益；本报告不授权或启动该训练，也不追加病例筛选、参数扫描或BNCal。

# 四模型开发集结果：科研解读补充 v1

本补充只解读已经完成的固定评分，不改变原数据、预测、评分、阈值或统计结果，不新增模型、bootstrap或正式gate。

**本轮没有验证16k输入能同时改善未知表面与接口。** 未知表面E的source平均P95由7.9496降为7.7629 mm，点估计降低0.1867 mm，约2.35%；但95%配对区间为[−1.4907,+1.0677] mm，仍允许收益或损害。不能把均值略降写成稳定胜出，也不能将区间跨0解释为两设置等效或16k永远无效。

J切壁P95的差值为−0.1534 mm，区间[−1.5111,+1.1686] mm；J的2mm覆盖由46.4619%降为45.3089%，差值−1.1530个百分点，区间[−4.1071,+1.7904]个百分点。接口三项覆盖阈值的点估计均下降，但区间均跨0，不能宣称已经证实改善或恶化。42个source中，E主误差21个改善、21个变差。

**两折方向相反。** Fold C的E点估计升高0.3273 mm、J的2mm覆盖下降4.2964个百分点；Fold D的E降低0.7008 mm、J覆盖增加1.9904个百分点。两折E区间均跨0，不能只挑Fold D作正面叙述。

**模型误差明显高于固定目标采样的表示误差。** GT8192控制的E P95为1.3297 mm、J P95为1.2576 mm、J的2mm覆盖为99.7040%；模型E约7.8–8.0 mm、J约11.1–11.3 mm、J覆盖约45–46%。GT控制不是严格最优上界，但这些差距提示，不能把主要误差简单归咎于8192点采样上限。整体位置、形状偏差和切壁覆盖遗漏等机制需要既有预测的剖面来区分，不能仅凭汇总指标认定某段代码有错。

Nop-D的E误差约29.4–29.7 mm，明显高于模型，说明模型并非只是复制已知表面，确实改善了未知区域覆盖；但Nop-D的J表现优于模型，符合其直接保留已知骨面及接口附近点的性质。因此，未知区域补全与已知接口信息保留需要同时处理，不能仅凭其中一项声称完成骨块重建。

A2的E差值为−0.1861 mm，与A1主终点−0.1867 mm接近；B参考全G差值为−0.1188 mm，与A1全G差值−0.1141 mm接近。固定参考没有提供明确16k胜出的相反证据；这些离散点参考也不认证连续mesh、实体闭合或临床贴合。

建议暂保留8k为默认输入预算，16k作为完整报告的表示对照；理由是当前未验证增加点数的稳定收益，而非已证明8k更优。下一步优先对既有D、GT-G和两模型预测做固定病例剖面对照，并结合原训练曲线区分定位、形状与接口问题，无需立即重训或BNCal。随后再制定匹配数据、fold、输出和训练预算的Mamba对照；接口条件必须来自残缺输入D，GT-G及J标签不能泄漏为推理输入。

本结论仅适用于当前B0 AdaPoinTr、固定seed0、SkullBreak开发来源。两折训练集有重叠，source区间不覆盖多seed训练不确定性，也不代表独立外部测试或Mamba收益。本轮不自动执行上述后续工作。
