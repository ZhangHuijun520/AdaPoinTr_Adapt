# 既有预测与接口输入／proxy 几何证据诊断

日期：2026-11-02。本机只读分析已有评分、预测、输入点集及历史 CPU surrogate；未加载模型或 checkpoint，未 forward、GPU 或训练。

## 主要判断

**输入点集确有接口覆盖不足，但不能单独解释最终预测误差。16k 明显增加输入接口支持，却没有转化为四模型结果中的稳定接口收益。模型表示、聚合、查询／解码或学习目标值得优先调查；现有证据不能把具体原因归为实际 proxy 特征丢失。**

本次只定位证据层次，不提出已有因果证明，也不自动改变采样、模型或训练配置。

## 已有预测与输入对照

420 个模型预测对应 210 个缺损病例、42 个来源、每来源五种缺损，Fold C/D 的各自开发集预测。指标来自已冻结 scoring 产物；本次重新配对分析，不重算 bootstrap。均值先每源五缺损平均再来源等权；由于每源同为五例，此处病例均值数值相同。计数是描述性病例计数，不将 210 个缺损当作独立受试者。

| 接口指标 | 8k输入组 | 16k输入组 |
|---|---:|---:|
| 输入 D 对 J 的 Cover@2mm | 60.955% | 84.527% |
| 模型预测对 J 的 Cover@2mm | 46.462% | 45.309% |
| 共同 GT 8k 点集对 J 的 Cover@2mm | 99.704% | 99.704% |
| 输入 D 对 J 的 P95，mm | 3.494 | 2.514 |
| 模型预测对 J 的 P95，mm | 11.274 | 11.121 |
| 预测 J 覆盖低于输入的病例数 | 158/210 | 205/210 |

J 是缺失骨块 G 与残缺骨 D 的共享切壁；Nop_D 输入对照只用于已知接口处的覆盖诊断，不能把其与模型的比较推广为未知表面补全质量比较。离散体素面中心及面积为评价参考，不是连续表面精确积分。

共同 GT 的结果表明：相同 8k 输出预算至少能够较充分表示该数据的 J，因此当前约 45% 的预测覆盖不应简单解释为“输出点数 8k 必然不足”。但这不排除解码器容量、学习分配或其他区域精度约束。

## proxy 证据的能力与限制

实际预测归档经 SHA256 核验，423 个文件中有 420 个 prediction NPZ，另为 inference_manifest.jsonl、inference_complete.json、resources.jsonl；没有 proxy 文件。所查预测 NPZ 仅有 prediction 键。预测工具源码只保存最终 prediction，未保存实际 FPS 索引、proxy 坐标、KNN 或中间特征。

已有六例 NumPy FPS 近似诊断可作几何证据，不能冒称实际 CUDA 取点。它使用 float64、首点 0、首索引 tie-break；真实运行的并列距离及数值路径未在本轮验证。该六例为先前 SkullFix/SkullBreak pilot，不是四模型完整开发病例的中间轨迹，不能把两组均值串接成同一条因果链。

| 历史六例近似阶段 | 8k 的 J Cover@2mm | 16k 的 J Cover@2mm |
|---|---:|---:|
| 原始输入 | 50.698% | 72.578% |
| 512 中心坐标 | 6.530% | 5.992% |
| 256 proxy 坐标 | 4.256% | 3.906% |
| 第一层中心的直接 16-NN 输入邻域并集 | 46.589% | 50.949% |

输入距 J 面中心 1mm 内的点，在第一层直接邻域并集中的总数加权保留比例分别为 88.382% 与 59.140%。这提示更密输入在固定中心和 k=16 下，新增几何支持未按同等比例保留；它不是学习特征保留率，也没有包含全输入第一层特征传播或多跳邻域。

源码链为 N 输入→512 中心→256 proxy，再进入 Transformer／query／decoder。局部特征会在取点前和取点后聚合，因此低坐标覆盖不能证明所有接口特征被丢弃。反过来，邻域包含点也不能证明其特征被有效利用。

## 当前可回答与不可回答的问题

- 可回答：8k 输入接口覆盖存在上限；16k 输入几何支持明显提高；已有预测没有充分再现已支持的接口；固定 proxy 预算存在潜在几何压缩瓶颈。
- 不可回答：实际 CUDA proxy 是否和近似索引相同；接口特征具体在哪层减弱；decoder、查询或 loss 各占多少责任；增加 proxy 或改 Mamba 是否会改善结果。
- 未获得临床解剖层标签，不把 J/E 自动称为全部内外板；单一训练 seed 不估计训练随机性。

## 下一步建议

不再继续曲率采样参数扫描，也不追加训练。若需要确定实际阶段原因，最小有信息量的下一步是另行开展 **当前两个固定病例 × 8k/16k 四模型的无更新轨迹诊断**：只保存实际 512/256 取点索引与坐标、相关 KNN 支持、最终预测，并确认与既有冻结预测的一致性，再量化接口覆盖变化。

这一诊断需要加载 checkpoint 和运行 forward，超出本轮授权，因此本次没有执行或实现新工具。即使取得坐标轨迹，仍不能单凭坐标证明学习特征的因果丢失；如需特征干预，应另制定有对照的科学问题，而不是直接增加模块重训。
