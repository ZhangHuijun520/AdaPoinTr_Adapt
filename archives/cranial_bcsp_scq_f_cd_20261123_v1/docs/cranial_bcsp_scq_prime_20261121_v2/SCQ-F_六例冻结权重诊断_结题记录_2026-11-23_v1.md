## 研究问题与已完成范围

在同一份已训练 F 权重上，额外局部读取的 query–邻域对应是否影响粗点坐标和完整骨块补全质量？使用 SCQ-PRIME Fold C、seed `2026112101` 的冻结 F 终点和原先固定的六个开发病例。每例依次运行 Native、恒等对照和错配，一次授权共 **18 次完整 forward、0 次 optimizer step**。正式诊断后冻结审计核验了 **18 份预测、24 个归档成员、三个校验文件、37 条资源记录**及相同的模型和 RNG 前后指纹。 [冻结权重六例干预协议](SCQ-F_冻结权重六例配对干预协议_2026-11-22_v1.md) · [诊断后冻结审计][diag]

错配只把 F 中实际送入残差头的 `fa`、`fm` 和固定投影输出作为一组重新分配，保留邻域组多重集合，用不含 GT 的确定性映射选供体。所有条件的 `Qraw` 和传入 LQI 八层的跨 Memory 索引逐项相等。错配后的 `Qused` 仍经由原有 query 几何、排序、自邻域和 FC 进入最终输出。逐例检查确认旧模型 Native 回放与恒等对照坐标差均为零。每例 256/256 个槽通过特征变化检查，每组新旧邻域最多共享 5 个索引。 [冻结几何复核][geo]

一次本机 CPU 评分共 12 行。六个 Native 行精确复现了历史 F 的全部数值指标和严重标志，随后计算六个错配行。评分后审计对 5 个评分文件、6 个执行文件与 31 个绑定文件实测哈希，并从病例行独立重建了配对汇总。 [正式评分后冻结审计][score]

## 已支持的主张与结题决定

**对这份冻结 F 权重及既定六例，保留额外局部读取的原生 query–邻域对应，有助于多数病例的缺失表面覆盖和共享切壁吻合。** 实测特征差异、零差异恒等对照及固定的 LQI 跨 Memory 读取支持这一干预归因。该错配有意破坏了 query 与条件的联合关系，因此观察到的损害只反映模型对本次干预的敏感性。F 相对 B 的整体训练收益、各组件的独立收益、跨折与跨种子稳定性以及临床结论各需独立证据。 [诊断后冻结审计][diag] · [评分后冻结审计][score]

六例诊断和既有 C0 置换对照分别收束。原 SCQ-PRIME 的 `T1_C_FAIL_STOP` 裁决保持有效。后续研究问题限于 **原样 F 相对同格 B 的整个路径增量能否在 Fold D 重现**。本记录未授权新执行，也未新增 forward 或评分。 [既有 C0 收束][c0] · [PRIME 实验报告](Cranial_BCSP_FullMamba_SCQ_PRIME_完整实验报告_zh_v1.md)
