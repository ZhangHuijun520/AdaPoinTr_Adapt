# SCQ-F Fold D B／F 两臂复现协议

2026-11-23（北京时间） · v1 草案 · 待确认

## 1. 研究问题与证据范围

原样 F 在 Fold D、相同 seed 和训练合同下，能否相对新训练的 B 改善缺失骨块表面覆盖，并维持预定的接口与尾部风险水平？本协议只有一个主要对比 **F−B**，估计额外局部读取、固定投影与残差路径组成的整体实用增量。 [SCQ-FV v2 原 F−B 判据][fv]

Fold C 的历史 B／F 对照中，F 的来源等权 E P95 降低 **3.654 mm**，95% 配对来源区间为 **[−5.371, −1.969] mm**，18/21 个来源改善。J Cover@2 提高 **8.031 个百分点**，严重病例由 **18 降至 4**，同时有 1 例新增严重。本次六例干预确认已训练 F 依赖额外读取的原生对应，并记录了 5/6 例覆盖和接口退化。两者为开展本复现提供依据。 [PRIME 原始两臂证据][prime] · [六例诊断结题][close]

Fold C 是 F 候选的发现折。Fold D 开发来源与 C 开发来源互斥，跨折训练数据存在重合，且项目历史已访问 Fold D。Fold D 仅承担同项目跨折复现。单 seed 结果、各组件的独立增量及外部数据适用性分别需要后续证据。SCQ-FV v2 的 C0 对照已收束，PRIME 的 `T1_C_FAIL_STOP` 保留。 [既有 C0 收束][c0] · [原划分与访问边界][fv]

## 2. 固定模型与配对合同

| 项目 | 计划锁定内容 |
| --- | --- |
| B，39,903,169 参数 | 原 FullMamba-LQI，保留 decoder 的原生局部读取、粗点传播及 FC 输出。 |
| F，40,596,676 参数 | 复用 PRIME F 的现有源码和数值合同。256 个 `Qraw` 各读 8 个 Memory 邻居，使用规范化特征的 mean、max 及固定 `Pfix` 七维投影。1802→384→3 GELU 残差头给出 δ，`Qused = Qraw + δ`。 |
| 固定投影及初态 | `Pfix` 为 7×384 FP32，SHA256 `495bf59bc8ee068fe5a2892c6545796404ad1d81cb7b5862a8c09e9491eb7589`。F 绑定 seed `2026112101` 的冻结新头初始化，末层零初始化。B/F 共有参数、持久 buffer 及训练起始随机流按原合同核对。 |
| Native 路径 | 两臂的 LQI 与 FC 使用原生行为。F 的 `Qused` 参与原生后续查询与跨 Memory 取邻。本次六例干预专用的固定 `cross_idx` 和错配适配器留在既有诊断范围。 |
| 数据 | SkullBreak BCSP-GeoV1 的完整边界 `∂D → ∂G`，沿用 V1 表面采样与 D-only 坐标。Fold D 固定 63 个训练来源／315 病例及 21 个开发来源／105 病例，按 canonical source 互斥，各来源五类缺损完整。 |
| 模型训练 | 新 `B_D` 后新 `F_D`，同一设备 UUID、GPU 驱动、实际算子、镜像与精度设置，从头训练。每臂 8192→8192、256 coarse、32 子点／父点、batch 8，100 次遍历 ×39 个完整批次，精确 **3900 更新、31,200 曝光、300 丢弃槽**。 |
| 损失与数值设置 | 沿用原 coarse＋dense Chamfer、reduction、AdamW 参数组、LR/BN 调度、原 provider、FP32 和 TF32／AMP 关闭合同。采用唯一末步 checkpoint，披露既有 CUDA 有限非位级确定性。 |
| 预测与评分 | 两臂均冻结后，在同一 105 例做 batch 1、FP32、eval 的 Native 预测，每臂 105 次，共 **210 次 forward、零更新**。统一 CPU 评分只生成 210 个新模型行。原 Nop_D／GT_8192 共享对照可在绑定一致时复用为口径核验。 |

两臂均继承同一份 D 折完整批次及丢弃顺序，逐步核对实际病例 ID、来源与曝光。冻结两臂共同初态及各自末步权重 SHA256 后，再开展开发集预测。训练阶段仅使用冻结训练来源；开发 GT 仅用于独立 CPU 评分及结果后审阅。官方测试、独立封存来源、SkullFix 与 MUG500+ 继续封存。 [PRIME 实际训练与数值合同][prime] · [既有 D 折资产索引][lock]

## 3. 评分、统计与判据

以同一 A1 参考面和 D-only 反归一化在世界 mm 下计算面积加权 E/J P95、J Cover@2。A2 的反向尾部以预测点到参考面的 P95，以及距离严格大于 20 mm 的比例 `far20` 表示。沿用严重状态 **E P95 >20 mm 或 J Cover@2 =0**。严重阈值用于既有离线几何风险定义。 [原 F−B 评分合同与阈值][fv]

各来源先等权平均其五个缺损病例的 F−B 差，再对 21 个来源等权。固定 **2,000 次 21 来源配对 bootstrap**，来源 ID 升序，沿用 PCG64 seed `2026112303`。保存抽样索引并用原精度裁决。报告 95% 百分位区间、21 个来源的胜负、五类缺损、105 对完整病例、全部新增／挽回／共同严重名单及逐来源留一范围。区间描述固定模型下的来源不确定性。 [原 F−B 统计合同][fv]

| 预先继承的指标 | F−B 通过条件 |
| --- | ---: |
| 来源等权 E P95 | ≤ −0.50 mm |
| E P95 改善来源数 | ≥ 14／21 |
| 来源等权 J P95 | ≤ +0.25 mm |
| 来源等权 J Cover@2 | ≥ −0.50 个百分点 |
| 来源等权反向 A2 P95 | ≤ +0.50 mm |
| 来源等权 far20 | ≤ +0.25 个百分点 |
| 严重总数 | F 不高于 B |
| 新增严重 | ≤ 2／105 |

**裁决顺序。** 训练或评分的绑定、完整性、配对或数值检查未通过，停止裁决并保留证据。主指标或风险条件任一未通过，按本次复现结果收束候选的追加投入。八项均通过时，E P95 的 95% 区间上界小于零可报告来源级区间支持；区间仍包含零时报告方向性复现及不确定性。第二种子只在本轮结果、风险和成本审阅后另行决定。 [原阈值和报告口径][fv]

效率复用上述 210 次 Native 预测的计时，按每臂同一前五例预热，保留全部病例预测。记录输入已上设备至 `Dense` 完成的同步时延，报告其余 100 例 P50／P95 和每臂峰值显存。F/B 的 P50 时延比或峰值显存比超过 1.50 时，第二种子先做成本审阅。设备或计时口径不匹配时，效率记为待核。 [原效率口径][fv]

## 4. 审核后的阶段与交付

```mermaid
flowchart LR
    accTitle: Fold D 两臂复现流程
    accDescr: 先核对已冻结的源代码和数据，再逐臂训练和冻结，最后统一预测评分并判定是否复现。
    proof["只读核对 D 折与 B/F 资产"] --> b_run["单独授权 B_D 并冻结末步"]
    b_run --> f_run["绑定同格证据，单独授权 F_D 并冻结"]
    f_run --> infer["统一 Native 预测并冻结"]
    infer --> evaluate["统一 CPU 评分并按八项判据裁决"]
```

1. **P0 本机只读差量核对。** 核对冻结 B/F 源码、种子与初态、D 折资产、实际模型构造与损失、provider、评分与顺序兼容性。核清可复用的真实 CUDA 训练与零更新证据适用范围，登记需要的最小差量。 [D 折原计划锁][lock] · [PRIME 训练及准入证据][prime]
2. **实施准备。** 计划确认并完成 P0 后，单独明确 Fold D 最小入口适配与针对性验证范围。若历史 B/F 真实 CUDA 证据覆盖冻结路径和设备数值条件，复用这些证据。若发现新的训练计算路径或数值条件缺口，冻结一个与该缺口对应的有限验证范围后另行授权。提交执行请求前锁定 CPU/GPU 预算、当前设备、输入与代码 SHA256、新输出路径和失败即停规则。
3. **逐阶段启动。** 同格先完成 B_D 的末步只读冻结审计，再创建绑定它的 F_D 请求。预测、评分、裁决分别提交审阅和授权。每个执行请求只允许一次，失败后保留凭据并停止。旧 C0 请求、历史 checkpoint 与 Fold C 评分用于追溯。
4. **最低交付。** 交付 B_D/F_D 训练配对冻结凭据及末步 checkpoint 哈希、210 份 Native 预测的成员哈希与状态/RNG 证据、病例配对评分、来源级统计、尾部名单、资源成本及决策记录。预测保留实际粗点和 Dense，F 另保留 `Qraw` 与 δ，供冻结后检查异常病例。

本草案待确认。本次只编写协议，P0 实际就绪、代码适配、准入、服务器核验及任何执行请求均留在后续单独授权阶段。
